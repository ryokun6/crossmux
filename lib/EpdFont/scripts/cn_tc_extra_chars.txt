# Traditional-only characters the Simplified 7000 pool cannot produce.
#
# The 14pt tier derives its charset from chars_7000_common.txt through OpenCC, so
# it can only contain Traditional forms that some Simplified character maps to.
# Characters with no Simplified counterpart never appear no matter how the
# conversion is widened: the Traditional pronouns 妳/牠/祢, older orthographic
# forms (卽 旣 眞 敍 朶), Japanese shinjitai quoted in translated works (実 発 雑),
# and given names such as 淼 (汪淼, 三體).
#
# Collected by scanning Traditional EPUBs for glyphs absent from the generated
# 14pt coverage. Before adding a character here, check it is genuinely outside
# the variant expansion in build-cn-builtin-fonts.sh — that path is preferred
# because it generalises, while this list only covers what someone has hit.
